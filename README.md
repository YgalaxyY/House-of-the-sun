## О проекте

Статическая страница гостевого дома с фотогалереей. Изображения можно листать кнопками, клавишами и жестами. Для контактов предусмотрено копирование.

Для просмотра запустите локальный статический сервер и откройте [index.html](index.html). Изображения находятся в [source](source). Страница использует HTML, JavaScript, Tailwind CSS и Feather Icons. Для внешних библиотек нужно подключение к интернету. [English](README.en.md).
