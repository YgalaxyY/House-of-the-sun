## ☀️ О проекте | Project Overview

**Дом Солнца** — это современный одностраничный веб-сайт (Landing Page) для частного пансионата. Проект разработан как готовое решение для бизнеса, ориентированное на удобство пользователей пожилого возраста и их родственников.

### Ключевые особенности:
- 📱 **Mobile First:** Полная адаптивность под любые устройства.
- 🎨 **UI/UX:** Теплая цветовая гамма (Amber palette) для создания атмосферы доверия.
- 🖼️ **Интерактивная галерея:** Модальное окно с поддержкой свайпов, навигации стрелками и закрытия по клику вне области.
- ⚡ **Performance:** Высокая скорость загрузки благодаря использованию CDN и чистого JS.

---

## 🛠 Технологический стек

* **HTML5 / CSS3** (Custom animations)
* **Tailwind CSS** — для быстрой и качественной верстки.
* **JavaScript (Vanilla)** — логика галереи, управление модальными окнами и системные уведомления.
* **Feather Icons** — минималистичный набор иконок.

---

## 💎 Реализованный функционал



1. **Copy-to-Clipboard:** Интеграция быстрого копирования адресов и телефонов (удобно для навигаторов).
2. **Smooth Animations:** Плавное появление блоков при загрузке страницы.
3. **Gallery System:**
    - Поддержка управления с клавиатуры (Esc, Arrows).
    - Touch-события для перелистывания на смартфонах.
    - Оптимизированный "zoom" эффект для фотографий.
